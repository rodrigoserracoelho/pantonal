# Pantonal logo

**Chosen mark: B2 · Cluster stem.** The letter P: its stem is a vertical
cluster (a vertical line in Chromatic Thinker plays every note it crosses) and
its bowl is made of notes, as drawn on the piano-roll grid.

Open [index.html](index.html) (through the local server, e.g.
http://localhost:5173/design/logo/) to see the final logo next to every concept.

## Files

| File | Use |
|---|---|
| `assets/logo/pantonal-mark.svg` | The mark on a transparent background; works on light and dark |
| `assets/logo/pantonal-logo.svg` | Mark + "pantonal" wordmark (needs the Fredoka font to render exactly) |
| `assets/logo/pantonal-app-icon.svg` | Mark on a full-bleed dark square, source for the PNG icons |
| `assets/icons/` | Favicon (SVG + 32 px PNG), Apple touch icon (180), app icons (192, 512) |
| `design/logo/concepts/` | Every concept explored, as standalone SVGs |

The PNG icons are rendered from `pantonal-app-icon.svg` with headless Chrome.
The mark sits inside the central 60% so circular "maskable" crops keep it.

## Concepts explored

1. **A · Twelve:** twelve notes in a circle with a drawn line.
2. **B · Piano-roll P:** the letter P built from piano-roll notes. Chosen direction.
3. **C · Glissando:** a glide, a cluster and a note over twelve pitch lines.
4. **D · Octave:** the twelve keys of an octave with a drawn line.

Variations on B: **B1** refined, **B2** cluster stem (chosen), **B3** with a
yellow playhead, **B4** bold for small sizes.
